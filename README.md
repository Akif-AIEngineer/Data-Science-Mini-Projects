## 📌 Project 1: Live API Data Extraction
This repository contains scripts for automated data extraction. The first project demonstrates how to fetch and parse live JSON data from a REST API using Python.

### 🛠️ Skills & Libraries Used:
* **Language:** Python 3 🐍
* **Libraries:** `requests` 🌐
* **Data Format:** JSON 📦

### 💡 Key Concepts Applied:
1. **API Connection:** Established a connection to an external open API endpoint.
2. **Data Parsing:** Converted raw JSON responses into structured Python dictionaries.
3. **Targeted Extraction:** Successfully targeted specific keys (like 'message' and 'status') to retrieve exact data points.
